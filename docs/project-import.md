# 导入 Codex 本地项目

点击侧栏项目旁的“＋”，选择已有 Codex 本地项目并点击“导入”。导入只将名称和目录关联写入 Task Workspace SQLite，不复制目录、不修改 Codex 配置，也不自动搬入历史会话或记忆。

列表按规范化后的实际目录去重，已关联目录显示“已导入”。不导入 ChatGPT 项目、远程目录或已不存在的目录。仍可通过“手动创建”添加新项目，并填写可选目录。

独立本地服务读取 Codex 桌面当前保存的项目元数据；该读取被隔离在适配器中，因为桌面内部状态文件不是稳定公共 API。格式无法识别或读取失败时显示提示，不通过扫描所有历史会话或硬编码本次项目列表兜底。
