# 中英文界面

界面支持简体中文和英文。首次加载依据浏览器语言选择（中文语言代码使用简体中文，其余使用英文）；手动切换后，选择保存在浏览器本地存储中。无法访问本地存储时仍可在当前页面切换。

语言入口统一位于侧栏的「设置」页，顶部与弹窗不再重复提供切换按钮。覆盖导航、看板状态、任务详情、表单、按钮、悬停提示和界面状态信息。任务名、项目名、用户记忆、会话摘要、证据和 Git 引用保留原文。数据库生成的 Markdown 和 Continue 原始上下文也保留原始内容，不通过字符串替换伪造翻译。

翻译集中在 `ui/i18n.js`。新增文案需同时补齐 zh/en 字典；`npm test` 检查键集合一致性和语言回退。业务状态值及 API 参数仍使用稳定的英文枚举。

设置页还提供任务动效开关，以及只读的本地存储说明和 Hook 采集状态。语言与动效偏好自动保存到当前浏览器；动效开启时仍遵循系统减少动态效果偏好。

验证：设置页可中英文切换；刷新后保留语言和关闭动效的选择，关闭后任务提示的 CSS 动画为 none。窄窗口仍可访问设置入口。自动检查覆盖字典键一致性、语言回退、模板插值不修改用户文本及常见错误本地化。
