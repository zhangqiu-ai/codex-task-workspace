# 本机日常可用性审计 · 2026-09-13

## 发布结论

**NO-GO：本机验收候选版，尚未批准生产部署。** 源码层关键缺陷已修复，本地运行及数据恢复验证通过；真实宿主安装、生命周期投递、会话续接和持续试用仍缺验收证据。不能把以下通过的测试换算成这些门槛已完成。

范围：单用户本机、Codex 内置浏览器面板、SQLite、项目/任务/会话/记忆、MCP 与 Hook、构建启动、备份恢复。未加入云同步、团队权限、原生导航、自动发送会话、移动端或复杂统计。没有修改用户源项目、历史数据、Codex 客户端或安装登录服务。

## 已修复的发现

| 领域 | 发现 | 修复与证据 |
|---|---|---|
| 数据库启动 | DDL 非原子，WAL 前未设置等待 | 事务初始化、失败关闭、锁等待顺序；保留既有数据回归 |
| 并发写入 | 任务先读后整行更新可能覆盖并发修改 | IMMEDIATE 事务覆盖读取/校验/更新；双连接回归 |
| 读取一致性 | state/context 多次查询可混入不同时间数据 | 可嵌套 savepoint 快照；并发提交及异常恢复回归 |
| Hook 顺序 | 延迟事件覆盖较新的工作目录 | cwd 跟随最新事件，保留最早创建时间；乱序回归 |
| HTTP | 跨站请求/超长流/错误响应边界 | 回环 peer、Host/Origin/Fetch-Site 校验、可靠 413、读取后发响应 |
| 服务生命周期 | 端口和关闭处理不完善 | 启动前校验端口、占用错误、超时、SIGTERM 重启；子进程测试 |
| MCP 生命周期 | stdio 结束未明确关闭 | EOF/SIGINT/SIGTERM 关闭 transport 与数据库 |
| UI 断连 | 静默保留旧数据 | 明确重试/旧数据提示，恢复清除连接提示；失败通知可关闭 |
| UI 操作 | 状态失败未回退、重复提交风险 | 回退选择、请求中防重复、表单保存保护、只读请求超时 |
| UI 一致性 | 详情不随外部变化、重绘焦点丢失 | 自动刷新详情、请求序号、编辑期间延后、保留焦点与滚动 |
| 语义 | 动效易被误认为执行监控 | 提示明确为 workflow status，继续保持真实运行证据边界 |
| 包格式 | defaultPrompt 与官方清单形状不一致 | 修正数组形状，官方插件与 skill validator 通过 |
| 运维 | 无可执行备份/恢复/检查流程 | maintenance CLI，在线一致备份，只恢复全新目录，权限保护 |
| 交付 | 无独立运行包/登录配置 | 测试后打包生产依赖、生成待部署 plist，不自动安装 |

## 验证证据

- Node 22.22.3；`npm test`：47/47 通过。
- 真实 SQLite 持久化、重开、并发写入、版本拒绝、迁移失败保留数据、外键及 integrity_check。
- SIGKILL 中断写进程：已提交任务保留，未提交事务回滚。
- 在线 WAL 备份 → 全新目录恢复 → 重开；数据库和记忆事实相同，拒绝覆盖现有目录。
- 10 项目、1,000 任务、2,000 会话关联的数据读取回归通过。此为代表性数据规模检查，不是 UI 大规模性能或长时间运行基准。
- MCP initialize/list/tool 往返、EOF 退出；三个 Hook 生命周期输入的真实子进程采集和错误隐私检查。
- HTTP 跨源/Host/Fetch-Site、超限请求、JSON、端口、关闭/重启回归通过。
- `npm audit --omit=dev`：0 个当前已知漏洞；不等于绝无安全风险。
- 官方 plugin validator 与 skill quick validator 通过（隔离 uv + PyYAML，不安装全局依赖）。
- 独立运行包仅安装生产依赖，启动后 `/api/state` smoke 通过。
- macOS 登录启动配置 `plutil -lint` 通过；尚未安装并实际登录测试。

## 非阻塞限制与后续观察

- 项目发现读取 Codex 内部本地状态格式，升级可能改变；未知结构失败关闭，保留手动创建入口。
- 会话 ID 没有天然保证是当前桌面可恢复任务，必须验证。Hook 收到事件也不等于完成 AI 总结。
- Git 引用是用户提供的基础关联，未检验 branch/commit 存在性；Promote 为草稿，不自动改权威文档。
- UI 没有删除/归档、标题重命名、分页、自动备份轮换；这些不应被宣称已经支持。
- 长时间磁盘满/断电、数万任务 UI、宿主升级兼容性不在已验证范围。
- 原始数据仅本机保存，应用没有独立用户鉴权；运行在同一用户身份的其他本地程序可访问数据。不要公网部署。
